# 🦠 Dashboard COVID-19 — Power BI

Dashboard interativo desenvolvido no Power BI para análise exploratória de dados globais da COVID-19, cobrindo o período de 22 de janeiro a 23 de março de 2020.

## 🎯 Objetivo

Este dashboard apresenta uma análise exploratória dos dados da COVID-19, permitindo acompanhar casos confirmados, mortes, recuperados e a evolução da pandemia ao longo do tempo e por país. O objetivo é transformar dados em informação, de forma clara e interativa, para facilitar a compreensão do impacto global da pandemia.

## 📊 Páginas do dashboard

| Página | Descrição |
|---|---|
| **Overview** | KPIs gerais (casos, mortes, recuperados, taxa de letalidade), mapa geográfico e evolução diária |
| **Países** | Filtro interativo por país com casos confirmados, mortes e novos casos |
| **Trends** | Evolução temporal de casos e mortes, além de comparação casos x mortes por país |
| **Comparações** | Análise comparativa de novos casos, novas mortes e novos recuperados ao longo do tempo |
| **Sobre o Projeto** | Objetivo, dados utilizados, análises realizadas e ferramentas do projeto |

## 🗂️ Dados utilizados

Dataset com informações sobre:
- Data
- País / Província-Estado
- Localização geográfica (latitude e longitude)
- Casos confirmados, mortes e recuperados
- Novos casos, novas mortes e novos recuperados

Fonte: Johns Hopkins CSSE (JHU CSSE COVID-19 Data)

## ✅ Análises realizadas

- Evolução temporal dos casos
- Evolução das mortes
- Recuperados ao longo do tempo
- Comparação entre países
- Taxa de mortalidade
- Relação entre novos casos e novas mortes

## 🛠️ Ferramentas

- **Power BI** — modelagem de dados e desenvolvimento dos visuais
- **DAX** — criação de métricas e cálculos
- **Excel/CSV** — fonte e tratamento inicial dos dados
